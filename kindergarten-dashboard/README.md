# داشبورد مدیریت مهدکودک

یک صفحه‌ی HTML فارسی و راست‌به‌چپ برای مدیریت روزانه‌ی مهد: کودکان، دریافت‌ها، چک‌ها و اقساط، پرسنل و حقوق، هزینه‌ها، رویدادها، تعرفه‌ها و خدمات.

- **اولین بار** فایل اکسل مهد را وارد می‌کنید (همان ساختار شیت‌های «کودکان»، «تعرفه‌ها»، «دریافت‌ها»، «اقساط و چک‌ها»، «پرسنل» و …).
- **از آن به بعد** همه‌ی تغییرات در خود داشبورد انجام می‌شود و اطلاعات در همان مرورگر ذخیره می‌شود.
- از **تنظیمات ← دریافت خروجی اکسل** نسخه‌ی پشتیبان با همان ساختار شیت‌ها (همراه «راهنما» و «تقویم») بگیرید.

## صفحه‌ی داشبورد

همه‌ی نمودارها در یک صفحه‌ی نئونی بنفش، یک نمودار برای هر شیت اکسل:

| شیت اکسل | نمودار |
|---|---|
| دریافت‌ها | دریافت‌های ۳۰ روز اخیر، دریافت به تفکیک دسته، روش دریافت |
| کودکان | شاخص‌های کلیدی، کودکان هر کلاس، گروه سنی و نوع حضور، ترکیب تعهد شهریه |
| خدمات | خدمات جانبی |
| اقساط و چک‌ها | سررسید چک و اقساط |
| تعرفه‌ها | تعرفه‌ها |
| پرسنل و پرداخت حقوق | پرسنل، هزینه و حقوق ۶ ماه |
| خریدها و هزینه‌ها | هزینه و حقوق ۶ ماه |
| رویدادها | رویدادها |

- دکمه‌ی **ارائه تمام‌صفحه** فقط نمودارها را روی کل صفحه نشان می‌دهد.
- با دکمه‌ی بزرگ‌نمایی گوشه‌ی هر کارت، همان نمودار بزرگ باز می‌شود.
- فیلترهای کلاس، گروه سنی و نوع حضور در نوار کناری همه‌ی نمودارها را با هم فیلتر می‌کنند.

## ساخت

```bash
# نسخه‌ی مستقل برای دسکتاپ (بار اول فایل اکسل را می‌پرسد)
python3 build.py desktop dist/mahd-dashboard.html

# پیش‌نمایش با اطلاعات اکسل داخل صفحه
python3 build.py demo Mahd.xlsx demo.html
```

فایل اکسل و خروجی‌های ساخته‌شده در مخزن ذخیره نمی‌شوند تا اطلاعات کودکان خصوصی بماند.
